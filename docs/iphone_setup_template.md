【ペットカメラの見かた・iPhone設定手順】

■ 用意するもの
・送った招待リンク（Tailscale というアプリの招待です）


■ 1回だけの設定（5分くらい）

1. App Store で「Tailscale」を検索してインストール
   （水色のアイコンのアプリ。無料です）

2. 送った招待リンクをタップして開く
   → 自分のGoogleアカウントかAppleアカウントでサインイン
   （こちらのアカウント情報は不要です。自分のもので大丈夫です）

3. Tailscaleアプリを開いて、画面のスイッチをオンにする
   → 「VPN構成の追加を許可しますか」と聞かれたら「許可」
   → iPhoneの画面の上に小さく VPN と表示されればOK

4. Safariで次のアドレスを開く

   https://（あなたのPCの名前）.（ネットワーク名）.ts.net:8443/viewer

5. PINを聞かれるので次の数字を入力

   （サーバの黒い画面に出ているPIN）

   長いですが、入力するのはこの1回だけです

6. 映像が出れば完了です
   ホーム画面に追加しておくと次から楽です
   （共有ボタン → ホーム画面に追加）


■ 通信量について

外出先（モバイル回線）で見るときは、動画なので通信量を使います。

  ・1分あたり およそ 10MB
  ・10分見ると およそ 100MB

長く見るときはWi-Fiのある場所がおすすめです。
「音を聞く」をオンにすると、少しだけ増えます。

見終わったら「CAMERA OFF」を押しておくと、
カメラ側のスマホの電池も長持ちします。
次に見るときは「CAMERA ON」を押せばすぐ映ります。


■ 2回目以降

・Tailscaleアプリのスイッチがオンになっていることを確認
・ブックマークしたページを開くだけ
（PINは覚えているので、もう入力は要りません）


■ 画面の見かた

DEVICE ONLINE … カメラが繋がっています
CAMERA ON     … カメラが動いています
CAMERA OFF    … カメラは止まっています
SOUND  ON/OFF … 音を拾っているかどうか


■ ボタンの説明

CAMERA ON      … カメラを動かす
CAMERA OFF     … カメラを止める
音を聞く        … 部屋の音を聞く
                 押してから音が出るまで数秒かかります
                 もう一度押すと止まります
スナップショット … 今映っている画面を写真に残す
                 （画像が開くので、長押しして「写真に追加」で保存）

♪ 音を鳴らす    … カメラを置いてある端末から音が鳴ります
                 猫の反応を見たいときに

                 音の種類は チャイム／呼びかけ／メロディ の3つ
                 音量は 小／大 の2つ

                 音の種類を押すと、手元でも同じ音が鳴ります
                 どんな音か確かめてから送れます


■ こんなときは

・画面が黒くて「タップして再生」と出る
　→ 映像の部分を1回タップしてください

・映像が止まった
　→ 10秒ほど待つと自動で戻ります。何もしなくて大丈夫です

・「CAMERA OFF」と出ていて映像がない
　→ 「CAMERA ON」ボタンを押してください

・「音を聞く」を押したのに音が出ない
　→ もう一度押してください。1回目で準備、2回目で鳴ることがあります

・「音を鳴らす」を押しても向こうで鳴っていないみたい
　→ 画面に「鳴らしました」と出ていれば送れています。
　　カメラ側のスマホの音量が下がっている可能性があります

・「DEVICE OFFLINE」と出ている
　→ カメラ側のスマホの問題です。こちらでは直せないので声をかけてください

・ページが開かない
　→ Tailscaleアプリのスイッチがオフになっていないか確認してください

・通信量を使いすぎていないか心配
　→ 見ていない間は「CAMERA OFF」にしておけば通信しません
　　ページを閉じるだけでも通信は止まります
