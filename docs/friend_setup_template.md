【ペットカメラの見かた・設定手順】

留守のあいだ、猫（メルク）の様子を見られるようにします。
iPhone でも Android でも同じように使えます。

アプリのインストールは1つだけ、設定は5分ほどで終わります。
見るときはブラウザで開くだけなので、専用アプリは要りません。


■ はじめに

家のカメラの映像は、登録した端末だけが見られるようになっています。
そのため、まず「見てもいい端末」として登録する必要があります。

その登録のために、こちらから「招待リンク」を送ります。
（Tailscale というアプリのネットワークに参加するためのリンクです）

このリンクが届いてから、下の手順を進めてください。


■ 事前に用意するものはありません

新しくアカウントを作る必要はありません。
Tailscale専用のIDやパスワードというものは存在しません。

ふだんお使いの Apple ID か Google アカウントでサインインすれば、
その場で登録まで終わります。


■ 1回だけの設定（5分くらい）

  ※ 順番が大事です。
    アプリを入れてすぐサインインすると、
    別のネットワークが新しく作られてしまい、映像が見られません。
    必ず先に招待リンクから参加してください。

1. アプリストアで「Tailscale」を検索してインストール
   （水色のアイコンのアプリ。無料です）

   iPhone → App Store
   Android → Google Play ストア

   → この時点ではアプリを開かなくて大丈夫です

2. 送った招待リンクをタップして開く

   → 招待を受ける画面（Accept invite）が出ます

   → サインインを求められたら、ふだんお使いのアカウントを選んでください

     iPhone なら「Apple でサインイン」
     Android なら「Sign in with Google」

   → 参加が完了すると、Tailscaleの画面に切り替わります

   ※ ここで入力するのは、ご自身のアカウントです。
     こちらのアカウント情報を使うことはありません。
     こちらから、そちらの端末の中身が見えることもありません。

3. Tailscaleアプリを開いて、手順2と同じアカウントでサインインする

4. アプリの接続スイッチをオンにする

   → このとき、端末から確認画面が出ます

     【iPhone の場合】
     「"Tailscale"がVPN構成の追加を求めています」
      VPN構成にはトラフィックのフィルタリングや
      モニタリングが含まれる場合があります。
              [許可しない]  [許可]

     →「許可」を押してください
     → 続けて Face ID かパスコードの確認が入ります

     【Android の場合】
     「接続リクエスト」
      Tailscale がVPN接続の設定を求めています。
              [キャンセル]  [OK]

     →「OK」を押してください

   ※ これは端末が必ず出す確認画面です。
     押さないと接続できません。出るのは最初の1回だけです。

   → 画面の上に小さく VPN と表示されればOK

   ※ アプリの中に「Exit Node」という項目がありますが、
     今回は使いません。触らないでください。

   ★ここで確認してください★

   アプリの画面に、パソコンやカメラの名前が並んでいますか？
   （takemunopc のような名前が見えるはずです）

   何も出ていない、または自分の端末だけしか出ていない場合は、
   別のネットワークに入ってしまっています。
   その状態では次の手順に進んでも開けません。声をかけてください。

5. ブラウザで次のアドレスを開く

   iPhone なら Safari、Android なら Chrome

   https://（あなたのパソコン名）.（あなたのtailnet）.ts.net:8443/viewer

6. PINを聞かれるので次の数字を入力

   （config.json の pin をここに書く）

   長いですが、入力するのはこの1回だけです

7. 映像が出れば完了です

   ホーム画面に追加しておくと次から楽です

   iPhone → 共有ボタン → ホーム画面に追加
   Android → メニュー（右上の点3つ）→ ホーム画面に追加


■ 家に来ているときは、こちらでも見られます

Tailscaleがうまくいかないときや、家のWi-Fiにつながっているときは、
次のアドレスでも見られます。

   https://192.168.x.x:8443/viewer

こちらは「接続はプライベートではありません」という警告が出ます。

   iPhone → 「詳細」→「このWebサイトを閲覧」
   Android → 「詳細設定」→「アクセスする」

自宅のパソコンが出している証明書なので、問題ありません。


■ 通信量について

外出先（モバイル回線）で見るときは、動画なので通信量を使います。

  ・1分あたり およそ 10MB
  ・10分見ると およそ 100MB

長く見るときはWi-Fiのある場所がおすすめです。
「音を聞く」をオンにすると、少しだけ増えます。

見終わったら「CAMERA OFF」を押しておくと、
カメラ側のスマホの電池も長持ちします。
次に見るときは「CAMERA ON」を押せばすぐ映ります。


■ 2回目以降

・Tailscaleアプリのスイッチがオンになっていることを確認
・ホーム画面に追加したページを開くだけ
（PINは覚えているので、もう入力は要りません）


■ 画面の見かた

DEVICE ONLINE … カメラが繋がっています
CAMERA ON     … カメラが動いています
CAMERA OFF    … カメラは止まっています
SOUND  ON/OFF … 音を拾っているかどうか


■ ボタンの説明

CAMERA ON      … カメラを動かす
CAMERA OFF     … カメラを止める
音を聞く        … 部屋の音を聞く
                 押してから音が出るまで数秒かかります
                 聞いている間はボタンが「音を止める」に変わります
スナップショット … 今映っている画面を写真に残す
                 （画像が開くので、長押しして「写真に追加」で保存）

♪ 音を鳴らす    … カメラを置いてある端末から音が鳴ります
                 猫の反応を見たいときに

                 音の種類は チャイム／呼びかけ／メロディ の3つ
                 音量は 小／大 の2つ

                 音の種類を押すと、手元でも同じ音が鳴ります
                 どんな音か確かめてから送れます

💡 ライトをつける … カメラ側のスマホのライトが点きます
                 寝ているところを起こさずに反応だけ見たいときに
                 3分で自動的に消えます
                 （対応していない端末ではボタンが出ません）


■ 「設定を開く」の中は触らなくて大丈夫です

画面の下に「設定を開く」というボタンがありますが、
ふだん使う操作は全部その上側にあります。

中にある「パソコンの電源」だけは、押さないようにお願いします。
家のパソコンが止まって、カメラが見られなくなります
（こちらが戻るまで直せません）。

ほかの項目は、触っても壊れるものではありません。


■ こんなときは

・画面が黒くて「タップして再生」と出る
　→ 映像の部分を1回タップしてください

・映像が止まった
　→ 10秒ほど待つと自動で戻ります。何もしなくて大丈夫です

・「CAMERA OFF」と出ていて映像がない
　→ 「CAMERA ON」ボタンを押してください

・「音を聞く」を押したのに音が出ない
　→ もう一度押してください。1回目で準備、2回目で鳴ることがあります

・「音を鳴らす」を押しても向こうで鳴っていないみたい
　→ 画面に「鳴らしました」と出ていれば送れています。
　　カメラ側のスマホの音量が下がっている可能性があります

・「DEVICE OFFLINE」と出ている
　→ カメラ側のスマホの問題です。
　　家に来られるときに、充電ケーブルが挿さっているか、
　　画面が点いていてページが開いたままか見てもらえると助かります。
　　それでも直らなければ声をかけてください

・「ページを開けません。ネットワーク接続を確認して…」と出る
　→ Tailscaleのネットワークに参加できていません。
　　アプリを開いて、パソコンの名前（takemunopc）が
　　一覧に出ているか確認してください。
　　出ていなければ、招待リンクからやり直す必要があります

・ページが開かない
　→ Tailscaleアプリのスイッチがオフになっていないか確認してください

・「VPN構成の追加」の画面を間違えて「許可しない」にしてしまった
　→ アプリのスイッチをもう一度オンにすれば、また出てきます

・招待リンクが届いていない／期限切れと出る
　→ 作り直して送るので声をかけてください

・通信量を使いすぎていないか心配
　→ 見ていない間は「CAMERA OFF」にしておけば通信しません
　　ページを閉じるだけでも通信は止まります


■ 旅行が終わったら

こちらで登録を解除します。そのあとは映像が見られなくなります。
Tailscaleアプリは不要になるので、消してしまって構いません。
